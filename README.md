# XTRA SWEETIES 🍭

Enjoy fresh ingredients, thoughtfully prepared meals, and a welcoming space designed for memorable moments. Experience bistro dining made simple and delicious.

![XTRA SWEETIES Banner](https://cdn.shadcnstudio.com/ss-assets/smm/marketing/shadcn-studio-smm-banner.png)

## Overview 🌏

**XTRA SWEETIES** is a modern, multilingual bistro website built with Next.js. It features a sleek design, interactive components, and full support for English and French languages.

Built with performance and aesthetics in mind, this project leverages the latest web technologies to provide a premium dining experience online.

---

## Features ✨

- **Multilingual Support:** Seamlessly switch between English and French.
- **Modern UI:** Built using Shadcn UI components and Tailwind CSS 4.
- **Responsive Design:** Optimized for all devices, from mobile to desktop.
- **Interactive Sections:** Hero section, popular dishes, about us, testimonials, and more.
- **Performance Optimized:** Leveraging Next.js 15+ features for fast loading and great SEO.
- **Animated Components:** Smooth micro-animations for an enhanced user experience.

---

## Tech Stack 🛠️

- **Framework:** [Next.js 15+](https://nextjs.org/)

## Getting Started 🚀

### Prerequisites

- Node.js 18+ 
- pnpm (recommended)

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd xtrasweeties
   ```

2. Install dependencies:
   ```bash
   pnpm install
   ```

3. Set up environment variables:
   Copy `.env.example` to `.env` and fill in the required values.
   ```bash
   cp .env.example .env
   ```

4. Run the development server:
   ```bash
   pnpm dev
   ```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Available Scripts

- `pnpm dev`: Runs the app in development mode.
- `pnpm build`: Builds the app for production.
- `pnpm start`: Starts the production server.
- `pnpm lint`: Runs ESLint for code quality.
- `pnpm format`: Formats code using Prettier.
- `pnpm check-types`: Runs TypeScript type checking.

## Project Structure 📁

- `src/app/[lang]`: Main application routes with internationalization.
- `src/components`: Reusable UI components and page blocks.
- `src/assets`: Data files, images, and other static assets.
- `src/lib`: Core logic, including i18n configuration.
- `public/locales`: Translation files for each supported language.
